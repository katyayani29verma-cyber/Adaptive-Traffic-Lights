# 🚦 Adaptive Traffic Light Control using YOLO & Machine Learning

An AI-based **Adaptive Traffic Signal System** that detects vehicle density using **YOLO (You Only Look Once)** and dynamically adjusts signal timing to reduce congestion, waiting time, and fuel consumption.

---

## ✅ Project Overview
Traditional traffic lights use fixed timers, causing:
- Long waiting times ⏳  
- Increased congestion 🚗🚗🚗  
- Wasted fuel ⛽  

This project makes traffic signals **smart** using Computer Vision and Machine Learning.

### 🔥 Features
- Detects vehicles using **YOLOv8**
- Counts vehicles per frame / image
- Generates dataset automatically in CSV format
- Displays bounding boxes with vehicle count
- (Upcoming) Integrates with **SUMO Traffic Simulator**
- (Upcoming) Predicts **optimal green time** using ML
